# Adithya Power - Refractories & Insulation

Official website for **Adithya Power Refractories and Insulation Pvt. Ltd.** — specialists in high-temperature industrial refractory manufacturing, thermal design engineering, material optimization, and turnkey shutdown installation and dry out.

---

## 🏗️ Project Overview & Architecture

This repository contains a responsive, dark-industrial, multi-page website built with semantic HTML5, modern Tailwind CSS styling, Google Fonts, and accessible vanilla JavaScript animations.

### Pages & Structure

- **`index.html`** — Primary homepage featuring:
  - Hero with furnace Ken Burns zoom and molten ember pulse.
  - Sticky navigation with scroll-spy and mobile drawer menu.
  - Section 01: About us & leadership experience counter.
  - Section 02: Core engineered services preview cards.
  - Section 03: Sector-by-sector technical capabilities.
  - Section 04: Industries we serve (Cement, Steel, Aluminium, Chemical, Petrochemicals).
  - Section 05: Specialized Project Execution and rapid shutdown support.
  - Section 06: Our Approach (Highlight band in warm off-white `#f4f1ec`).
  - Section 07: Board Members & Executive Leadership grid.
  - Section 08: Interactive enquiry contact form & corporate details.
- **`refractory-material-manufacturing.html`** — Dedicated page for PCPF shapes, monolithics, ceramic fibers, microporous boards, and 10 brick grades.
- **`design-engineering.html`** — Dedicated page for thermal analysis, 3D modeling, anchor layout, and failure RCA.
- **`material-selection-optimization-supply.html`** — Dedicated page for slag resistance profiling, optimization, and logistics.
- **`installation-and-dry-out.html`** — Dedicated page for certified turnkey installation and programmatic gas burner dry-outs.
- **`assets/`** — High-resolution photos, equipment photography, leadership portraits, and company branding.

## 🚀 Local Development

To run and preview the site locally on your computer:

### Option 1: Using Node (Recommended)
```bash
npx serve .
```
Then open `http://localhost:3000` in your browser.

### Option 2: Using Python 3
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

### Option 3: VS Code Live Server
Right-click on `index.html` in VS Code and select **Open with Live Server**.

## 🌐 Deployment Instructions

### Deploy to GitHub Pages (Built-in Static Hosting)
1. In your GitHub repository:
   - Go to **Settings** &rarr; **Pages**.
   - Under **Build and deployment** &rarr; **Source**, choose **Deploy from a branch**.
   - Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
   - Your site will be published live at `https://<your-username>.github.io/<repo-name>/`.

### Deploy to Vercel or Netlify
- Simply import your GitHub repository into [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
- No build configuration is required (it deploys immediately as a zero-config static site).
